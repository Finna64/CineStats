# CineStats
CineStats is a web app in development that turns your Letterboxd viewing history into personalised film statistics.
Setup

1. Get an API key from OMDb.
2. Create a .env file in the project root.
3. Add your key to the file:
   API_KEY=your_omdb_api_key_here
   
Keep .env out of version control by adding it to .gitignore.
